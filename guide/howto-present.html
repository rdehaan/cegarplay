How to record and present a run

Goal: show a run in a talk or a report, step by step, without running it live.

The example

Every fast library example has a replay; voting-justification has one too, with a view of the profiles. Open voting-justification

Steps

  1. Record. Loop tab, Recording: every step (or the first N, every N-th, a sample), and solver calls for the timeline. Run.
  2. Save. Project, Recordings, Download recording: a .cprec file. Open recording replays it later without the engine.
  3. Pick the moments. In the Observatory, the cursor drives every view; mark the steps that matter (the first refinement, an unsound one caught by the audit, a core shrinking) and export a storyboard strip or the view as SVG.
  4. Link it. A link with ?replay=examples/replays/ID.cprec, &step=N and &view=view opens a replay on a step; &lecture=1 shows the view alone with its notes as captions, for a projector.

Pitfalls

  • Recording every step of a long run makes a large file; record the first N steps or a sample.
  • A replay link works only for files in examples/replays/; a file of your own is opened with Open recording.
