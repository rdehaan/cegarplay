    The shared fragment
    
        
    Rules that every solver needs: domains, constants, common definitions. In the default
          loop it is part of the abstraction solver, the check solver and the glue.
    
      
    
    
    
  
    
  
    
    
    
      
    
      
    
        
    The abstraction fragment
    
        
    Proposes candidates. It over-approximates the solutions: every solution is a candidate,
          but a candidate may be refuted by the check. Refinements make it more precise.
    
        
    For rule refinements it may contain a part #program refine(k).; the loop
          grounds it once per counterexample with facts such as cex(k, T). Every head
          in that part must mention k, or the second refinement has no effect.
    
      
    
    
    
  
    
  
    
    
    
      
    
      
    
        
    The glue fragment
    
        
    Says which atoms the abstraction and the check share. Every atom glue(T) it
          derives makes T an interface atom: its value in a candidate is passed to the
          check as an assumption.
    
        
    Files written for the old prototype list the atoms without glue(...); the
          link then needs the keyword legacy.
    
      
    
    
    
  
    
  
    
    
    
      
    
      
    
        
    The check fragment
    
        
    Looks for a counterexample to the candidate, given the values of the interface atoms.
          If it finds one, it marks with relevant(T) the interface atoms the
          counterexample depends on. The refinement then says: one of these atoms must change.
    
        
    If relevant/1 marks too few atoms, the refinement also removes good
          candidates; compare with the Reference run template to find out.
    
      
    
    
    
  
    
  
    
    
    
      
    
      
    
        
    The loop script
    
        
    Declares the solvers (solver A = shared + abstraction), the links between
          them (link G = A -> C via shared + glue) and how they call each other.
          Start from a template; the Tutorial tab explains the language (lesson 7), and the
          manual has the full reference.
